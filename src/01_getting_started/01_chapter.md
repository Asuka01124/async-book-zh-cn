# 入门

这是本书保留的旧版章节入口，英文正文由 GPT-6 Luna 完整翻译，GPT-6.1 Sol 校审。第一次阅读也可以从新版[指南导读](../part-guide/intro.md)开始；实现细节和进阶主题可接着阅读[参考部分](../part-reference/implementing-futures-streams.md)。以下保留旧版的学习顺序与内容目标；具体语言行为以当前 [Rust Reference](https://doc.rust-lang.org/reference/items/functions.html#async-functions) 和 [Future 文档](https://doc.rust-lang.org/std/future/trait.Future.html)为准。

欢迎阅读《Rust 异步编程》！如果你正打算开始编写异步 Rust 代码，那么你来对地方了。无论你要构建的是 Web 服务器、数据库还是操作系统，本书都会介绍如何使用 Rust 的异步编程工具，充分发挥硬件的性能。

<a id="what-this-book-covers"></a>
## 本书内容

本书旨在成为一份全面且与时俱进的指南，帮助读者使用 Rust 的 async 语言特性和库，无论你是初学者还是经验丰富的开发者，都能从中受益。

- 前几章介绍异步编程的一般概念，以及 Rust 对异步编程的独特实现。

- 中间几章讨论编写异步代码时可用的重要工具与控制流机制，并介绍如何遵循最佳实践来组织库和应用程序，从而最大限度地提升性能和可复用性。

- 本书最后一部分介绍更广泛的异步生态，并通过多个示例讲解如何完成常见任务。

说完这些，让我们一起探索 Rust 异步编程的精彩世界吧！
